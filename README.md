# React Native App with Expo

This is a React Native app using Expo. Follow the instructions below to get started with the project.

## Prerequisites

Make sure you have the following installed:

- **Node.js** (Recommended version: 18.x or later)
- **npm** (npm comes with Node.js, but if it's not installed, you can install it separately)
- **Expo CLI** (Global installation)
- **Git** (Optional but recommended)
